# WhatIfs Asset Library v1

Purpose: reusable visual system for high-retention explainer Shorts.

## Scene roles
- hook: first-frame / first-sentence attention grabber
- example: relatable real-world setup
- mechanism: show what is physically/biologically/technically happening
- interrupt: visual reset / reaction / contrast / meme-style beat
- payoff: satisfying reveal / conclusion

## Rules
1. Scene role is chosen before asset type.
2. Character is a host, not decoration.
3. Every visual must add information or emotion.
4. Reuse is allowed, but do not repeat the same composition twice in a row.
5. Prefer mixed scenes: host + object + frame/text/overlay.
6. Mobile readability first.

## Library structure
- character/poses
- character/expressions
- frames
- overlays
- backgrounds
- objects/phone-battery
- objects/biology
- objects/wifi-signal
- manifests

The binary image pack is generated separately; manifests and selectors in this folder are the source of truth for automation.
